# Portfolio personal — Fran Fernández

## Sobre el proyecto

Este repositorio contiene mi portfolio personal, una página web donde presento mi perfil como desarrollador web, las tecnologías con las que trabajo y algunos de los proyectos en los que he participado.

## Tecnologías utilizadas

- HTML5 para la estructura de la página.
- CSS3 para el diseño y la adaptación a diferentes dispositivos.
- JavaScript para las interacciones y el selector de idioma español/inglés.
- Git y GitHub para el control de versiones y el alojamiento del proyecto.

## Contenido de la web

- Presentación personal.
- Información sobre mi perfil y formación.
- Tecnologías y herramientas que utilizo.
- Selección de proyectos.
- Información de contacto.
- Selector de idioma español/inglés.

## Proyectos destacados

El portfolio incluye una selección de proyectos personales y académicos, además de una plataforma de gestión empresarial desarrollada con React y Supabase.
